经济循环：为什么 产出 = 支出 = 收入

先把话说透：三本账记的是同一笔钱

早餐店这个月卖了 3 万元包子。这笔钱在经济学里同时是三件事：

视角谁在记这笔钱叫什么
买的人花了 3 万购买者（家庭）支出
店里做出 3 万的包子生产者（企业）产出
这 3 万变成工资、利润等发出去要素所有者（家庭）收入

一笔交易，三个账本，金额必然相同——因为它们不是三次不同的交易，而是同一枚硬币在循环里被三次"看到"。买者的支出不会凭空消失：它一离开你的口袋，就成了卖者的收入；卖者拿到钱，又源自他卖出的东西（产出）。买者不买、产出卖不掉、收入发不出——三者同涨同跌，所以恒等：

产出 = 支出 = 收入

这不是三条规律恰好相等，而是同一笔货币循环流的三种记账角度。循环流程图画的，就是这条看不见的"货币环河"。

现实中的经济循环，经济学是怎么简化的

现实经济每天发生几十亿次交易：有政府、银行、股市、外贸、网购、地摊……不可能全画进一张图。经济学家做了三层"雕刻"——每按一次下面的按钮，就多雕一刀（或先看最简版，再逐步还原）：

① 两部门：先假设世界上只有家庭和企业两个主体，没有政府、没有储蓄银行、没有外贸——这是教科书刻意做的"最小化实验"。看内圈（冷色）：家庭把劳动流向企业，企业把产品流回家庭，这是实物流；看外圈（暖色）：家庭支出的货币向上流，企业发出的收入向下流，这是货币流。两层循环方向相反、金额对应：产品换钱、劳动换钱，谁也不欠谁。下一刀，把被我们"关掉"的现实一层层放回来。

出口 X = 注入		完整的四部门恒等式：Y = C + I + G + NX

注意一个反复出现的对称结构：每一刀都同时引入一条漏出和一条对应的注入。这暗示了宏观均衡的核心思想——

均衡条件：总漏出 = 总注入（S + T + M = I + G + X）

漏出是"环里的水被舀出去"，注入是"往环里补水"。水位（总产出）升降，不看某一笔钱，只看总漏出与总注入谁大。这个水位，就是 GDP 的涨落。

为什么这种循环思想在宏观经济学中"再强调也不为过"

1 · 它直接生成了 GDP 的三种核算方法

既然产出 = 支出 = 收入，就可以从三个口子各量一次 GDP：生产法（数最终产品）、支出法（C+I+G+NX）、收入法（工资+利息+租金+利润）。三种方法不是三种不同的 GDP，而是同一条循环河在三个水文站的读数——所以教材第 9 章图 9-1 就是循环图，恒等式就从这里长出来。

2 · "一个人的支出是另一个人的收入"——乘数效应的心脏

你花 100 元买包子 → 店主收入 +100 → 店主按边际消费倾向花掉比如 80 元 → 面粉商收入 +80 → 再花 64 元……支出变收入、收入再变支出，循环像回声一样衰减但层层传递，加总远大于最初的 100 元——这就是乘数。没有循环思想，乘数公式 α = 1/(1−MPC) 只是个代数把戏；有了循环思想，它就是"环里多注一瓢水，全河都涨水"。

3 · 萧条与繁荣，都是循环在转快或转慢

回头看 01 PPT 那个"没煤"的对话：不买煤 → 煤商收入减少 → 煤商少买米 → 米商收入减少 → ……每个人"理性地捂紧钱包"，加总起来却是全体收入下降——支出的收缩沿着循环自我实现。大萧条就是一次大规模的"环流转慢"；凯恩斯革命开出的药方（政府增加购买 G），本质是从外面往环里强行注水，把漏掉的需求补回来。第 2 章的均衡收入决定、第 6 章的财政货币政策，全部建立在这幅图上。

自测三题（先自己想，再点开）

① 政府给公务员发工资计入 G，给低保户发补贴却不计入 G——用循环图解释区别。

公务员工资换来的是当期的公共服务产出（守边、办证、教学），钱是买产品/服务进入循环的支出，计入 G；低保补贴是单纯的转移支付——钱换了主人，但循环里没有对应的新产品流出来（低保户拿钱去买菜时，才作为他的 C 进入循环）。判据：看支出有没有实物/服务流与之对应。

② 假如家家都增加储蓄，而企业不增加投资，循环的水位怎么走？

储蓄是漏出，投资是注入。漏出 > 注入，环里货币变少 → 企业的销售额（产出）下降 → 发给家庭的收入下降 → 家庭被迫削减消费甚至储蓄本身——最终总收入收缩，储蓄总量未必增加（因为收入基数变小了）。这就是著名的"节俭悖论"伏笔，第 2 章正式登场。

③ 央行降息，用"漏出-注入"的语言说一遍传导路径。

降息 → 储蓄的回报降低、贷款成本降低 → 储蓄漏出减少、投资注入增加 → 注入 > 漏出，循环扩张 → 产出与收入上升。一句话：利率是调节"漏出与注入"的闸门之一——这是第 3 章 LM 曲线的直觉底子。
