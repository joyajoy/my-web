A · 导论（01 PPT）

A1 经济学的起点：稀缺性

经济学研究社会如何管理稀缺的资源。资源（人力、自然、资本）是有限的，欲望是无限的——「物以稀为贵」。由此引出每个社会都绕不开的三个问题：生产什么？怎么生产？为谁生产？

A2 经济学的思维方式

  • 稀缺思维：有选择就有代价——选择的代价就是机会成本（放弃了的最优替代）。
  • 自私假设 + 成本收益考量：亚当·斯密的「面包师」——面包师给我们烤面包不是因为仁慈，而是因为自利；人人自利，通过市场反而实现互相服务。
想一下：你上大学的机会成本是什么？（不只是学费）

机会成本 = 为上大学放弃的最高价值的替代用途。除了学费、书费这些显性支出，最大的隐性项往往是这四年去工作能挣到的收入。所以经济学意义上的"成本"比会计意义上的大。

A3 经济学的研究方法

  • 均衡分析：整体是均衡，个体是最优。
  • 边际分析：局限条件变化后，自利的个体如何重新选择——自变量变一个单位，因变量变多少。管理决策最常用。
  • 模型：用文字、图像或数学描述经济变量之间的关系，借鉴物理概念（弹性、均衡）。
  • 实证 vs 规范：唯一区别是是否做了价值判断。实证回答"是什么"，只描述不评价；规范回答"应该是什么"，要作好坏评价。

2024 年我国 GDP 增长 5.0%

政府应该提高最低工资标准

上月城镇调查失业率为 5.2%

通货膨胀比失业更可怕

A4 微观 vs 宏观：一句话分清

微观经济学宏观经济学
研究对象消费者、生产者、市场国民收入、就业、经济增长
核心理论价格理论货币理论
视角个体（家庭、企业）社会总体和总量

宏观要解决的核心问题：一个国家的总供给和总需求如何实现平衡。

A5 大萧条与凯恩斯革命：宏观经济学怎么诞生的

1929–1933 大萧条：产品卖不出去 → 企业减产裁员 → 收入下降 → 购买进一步减少……「爸爸失业没钱买煤，因为煤太多了」。市场自己转不出这个死循环。

凯恩斯的诊断：根源是有效需求不足（有效需求 = 购买的欲望 + 购买的能力），市场机制无法自动稳定总体经济，政府必须伸出「有形的手」干预。"In the long run, we are all dead."——长期等不起。

标志性事件（考试爱考年份）：1936 年凯恩斯《就业、利息和货币通论》发表——宏观经济学的诞生标志。

B · GDP（02 PPT 第一节）

B1 定义（原文背下来）

GDP = 经济社会（一国或一地区）在一定时期内运用生产要素所生产的全部最终产品（物品和劳务）的市场价值

现状数据：2024 年我国 GDP 达 1349084 亿元，比上年增长 5.0%。GDP 发明于 1934 年（库兹涅茨等），1944 年布雷顿森林会议正式成为衡量一国经济总量的主要工具。

B2 六个要点（每个都是考点）

要点内容易错点
① 市场价值用货币衡量、在市场上交易非法活动、家庭内部服务不计入
② 最终产品只算最终出售给消费者的产品和服务中间产品（面粉、原材料）不计入；价值增值之和 = 最终产品价值
③ 生产的而非售卖的算"本期生产的"，不算"本期卖掉的"企业存货计入；卖库存不增加当年 GDP
④ 一定时期通常一年，是个流量流量 = 发生额；存量 = 余额（存款数字不是 GDP）
⑤ 国土原则一国地域内生产的总价值外国人在中国生产→计入中国 GDP；姚明在美国打球→计入美国的 GDP、中国的 GNP
⑥ 对比 GNPGNP 按国民原则：一国居民的收入GNP = GDP + 来自国外的要素报酬 − 支付给国外的要素报酬

B3 循环流程图：为什么 产出 = 支出 = 收入

两部门模型（家庭 + 企业）：家庭向企业供给劳动等要素（实物流，图内圈），企业付工资利润、家庭花钱买产品（货币流，图外圈）。以「包子」为例：上半圈，GDP = 生产包子得到的总收入 = 工资 + 利润；下半圈，GDP = 家庭买包子的总支出。所以三种角度量的是同一个东西：

产出 = 支出 = 收入

这就是「三种核算方法」的理论根基（收入法对应收入角度，支出法对应支出角度）。想把这个循环看动画、逐层还原（两部门 → 金融市场 → 政府 → 国外部门），用这页交互动画：经济循环：为什么 产出 = 支出 = 收入。

B4 支出法：GDP = C + I + G + NX

  • C 消费：家庭日常支出——买衣服、吃饭、看电影、买手机。买二手车不算（以前生产过）。
  • I 投资：能产生收入的"实体投资"——建厂房、买机器设备、买新房（新建住宅属于投资，不属于消费！）。不是买股票那种金融投资。存货变动也算投资。
  • G 政府购买：政府办公路、建学校、发公务员工资、采购国防装备。低保、养老金、失业救济金等转移支付不算 G——发给个人后由个人去消费，那时才算 C。
  • NX = 出口 X − 进口 M：外国人买咱们的算加项；咱们的进口是别国生产，从总支出中减掉。买法国香水：算入 C 的同时作为进口减掉——对 GDP 净效果为零。

部门模型对应简化式：两部门（家庭+企业）Y = C + I；三部门（+政府）Y = C + I + G；四部门（+国外部门，开放经济）Y = C + I + G + NX。我国拉动经济的三驾马车——投资、消费、出口——正对应 I、C、NX。

B6 GDP 的不完美（论述题素材）

  • 不反映非市场交易活动：家务劳动、地下经济；
  • 不反映环境污染和资源消耗；
  • 不反映收入分配的公平与合理；
  • 不反映居民的生活感受（诗和远方不算数）。
